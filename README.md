# SecureChat

Web-based Secure Messaging App with AES-256-GCM + RSA-PSS/RSA-OAEP.

## Overview
SecureChat is a web-based secure messaging application that demonstrates end-to-end confidentiality, integrity, and authentication. It includes an Attack Lab to demonstrate various attacks and defenses.

## Installation
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Initialize database: `python scripts/init_db.py`
4. Run application: `python backend/app.py`
